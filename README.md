# pkg.guide — гид по менеджерам зависимостей (NPM / Composer)

**Ссылка на живой сайт (GitHub Pages):** _добавьте после деплоя_ → `https://github.com/vlksmoky/NPM-Composer-site`

## О проекте

Учебный проект — тематический адаптивный сайт-справочник о системах управления зависимостями: NPM (JavaScript) и Composer (PHP). Включает 8 связанных страниц, свёрстанных с использованием 12-колоночной сетки **Susy 3** (Flexbox) и методологии БЭМ.

ФИО студента: Панова Елизавета Сергеевна
Группа: 835
Тема проекта: Использование систем управления зависимостями (NPM, Composer)  
CSS-сетка: Susy 3 / Custom Flexbox Grid (без внешних тяжёлых фреймворков)

## Страницы сайта

1. `index.html` — Главная страница с промо-блоком и обзором возможностей
2. `pages/about.html` — О менеджерах зависимостей (сравнительная таблица NPM vs Composer)
3. `pages/npm.html` — NPM подробно (package.json, команды, этапы установки)
4. `pages/composer.html` — Composer подробно (composer.json, автозагрузка PSR-4)
5. `pages/commands.html` — Шпаргалка команд (таблица соответствия NPM ↔ Composer, стилизация командной строки CMD)
6. `pages/materials.html` — Учебные материалы (видео, ссылки для дальнейшего изучения, подписка)
7. `pages/glossary.html` — Глоссарий терминов с живым поиском
8. `pages/contacts.html` — Контакты (адаптивная форма обратной связи)

## Технологии

- **HTML5**: Семантическая доступная вёрстка (`main`, `nav`, `aside`, `header`, `footer`).
- **CSS3 / SCSS**: 
  - Сетка на базе **Susy 3** (12-колоночная адаптивная верстка через Flexbox).
  - Методология **БЭМ** (Block Element Modifier) для именования CSS-классов.
  - Кастомная стилизация интерактивных элементов, таблиц и блоков с кодом/терминалом в стиле классической консоли (CMD/Terminal).
- **Vanilla JavaScript** (`js/script.js`):
  - Подсветка активного пункта меню навигации.
  - Управление мобильным бургер-меню.
  - Функция копирования команд из терминала в буфер обмена в один клик.
  - Живой фильтр/поиск по терминам в глоссарии.
  - Плавающая кнопка быстрого прокрута «Наверх».
- **Шрифты**: Google Fonts (*Space Grotesk*, *Inter*, *JetBrains Mono*).

## Как запустить локально

Сайт полностью статический, сервер не нужен:

1. Скачайте или склонируйте репозиторий.
2. Откройте `index.html` в браузере — можно двойным кликом или через расширение **Live Server** в VS Code (правый клик по файлу → «Open with Live Server»).
