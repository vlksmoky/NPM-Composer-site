Composer — менеджер пакетов для PHP

Composer устанавливается отдельно от PHP и решает ту же задачу, что NPM для JavaScript: скачивает библиотеки из реестра Packagist и настраивает их автозагрузку в проекте.

Как подключить библиотеку к проекту

Инициализировать проект

Команда создаёт файл composer.json — манифест зависимостей, аналог package.json в мире NPM.

Установить зависимость

Пакет скачивается в папку vendor/, а запись о нём добавляется в composer.json.

Проверить composer.lock

Как и package-lock.json у NPM, этот файл фиксирует точные версии всех зависимостей для воспроизводимой сборки.

Подключить автозагрузчик

В коде достаточно один раз подключить vendor/autoload.php — дальше все классы из зависимостей доступны без ручных require.

Базовые команды

composer 
composer init
composer require guzzlehttp/guzzle
composer require --dev phpunit/phpunit
composer remove guzzlehttp/guzzle
composer update
composer dump-autoload

Пример composer.json

composer.json 
{
  "name": "acme/my-app",
  "require": {
    "php": "^8.1",
    "guzzlehttp/guzzle": "^7.8"
  },
  "require-dev": {
    "phpunit/phpunit": "^10.0"
  },
  "autoload": {
    "psr-4": {
      "App\\": "src/"
    }
  }
}

Блок autoload с правилом PSR-4 говорит Composer: классы из пространства имён App\ искать в папке src/.

require vs require-dev

В require — зависимости, нужные приложению на боевом сервере. В require-dev — инструменты для разработки и тестов (например, PHPUnit).
