NPM и Composer: в чём разница

Оба инструмента — менеджеры зависимостей: они скачивают библиотеки, хранят список зависимостей проекта в отдельном файле и следят за версиями. Разница — в экосистеме, вокруг которой они выросли.

Сравнение NPM и Composer
Параметр NPM Composer
Язык / платформа JavaScript, Node.js PHP
Файл-манифест package.json composer.json
Lock-файл package-lock.json composer.lock
Публичный реестр пакетов npmjs.com packagist.org
Папка с установленными пакетами node_modules/ vendor/
Автозагрузка кода через require() / import через автозагрузчик PSR-4
Команда установки зависимости npm install пакет composer require пакет

Что общего у всех менеджеров пакетов

  • Хранят список зависимостей отдельно от кода — в манифесте.
  • Используют семантическое версионирование (semver): МАЖОР.МИНОР.ПАТЧ.
  • Фиксируют точные версии в lock-файле, чтобы сборка была воспроизводимой.
  • Умеют разделять зависимости на «для продакшена» и «только для разработки».
