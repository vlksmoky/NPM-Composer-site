Шпаргалка команд

Одна и та же задача — разные команды. Держите эту таблицу под рукой в первые недели.

Соответствие команд NPM и Composer
Задача NPM Composer
Создать манифест проекта npm init -y composer init
Установить все зависимости из манифеста npm install composer install
Добавить новую зависимость npm install пакет composer require пакет
Добавить dev-зависимость npm install -D пакет composer require --dev пакет
Удалить зависимость npm uninstall пакет composer remove пакет
Обновить все зависимости npm update composer update
Показать устаревшие пакеты npm outdated composer outdated
Проверить уязвимости npm audit composer audit

Скопировать сразу обе команды

quickstart 
# NPM
npm install

# Composer
composer install
