NPM — менеджер пакетов для JavaScript

NPM (Node Package Manager) устанавливается вместе с Node.js и решает две задачи: скачивает пакеты из реестра npmjs.com и запускает скрипты, описанные в проекте.

Как подключить библиотеку к проекту

Инициализировать проект

Команда создаёт файл package.json — манифест, где будут перечислены все зависимости.

Установить зависимость

Пакет скачивается в папку node_modules/, а запись о нём добавляется в package.json.

Проверить package-lock.json

NPM фиксирует точные версии всех зависимостей (и их собственных зависимостей) — это гарантирует одинаковую сборку у всей команды.

Закоммитить lock-файл в Git

А вот node_modules/ в Git обычно не кладут — его добавляют в .gitignore, он всегда восстанавливается командой npm install.

Базовые команды

npm 
npm init -y
npm install axios
npm install --save-dev eslint
npm uninstall axios
npm update
npm run build

Пример package.json

package.json 
{
  "name": "my-app",
  "version": "1.0.0",
  "scripts": {
    "start": "node index.js",
    "build": "webpack --mode production"
  },
  "dependencies": {
    "axios": "^1.6.0"
  },
  "devDependencies": {
    "eslint": "^9.0.0"
  }
}

Значок ^ перед версией означает «любая совместимая минорная версия» — подробнее об этом в глоссарии про semver.

dependencies vs devDependencies

В dependencies — то, что нужно приложению в продакшене (например, axios). В devDependencies — инструменты только для разработки (линтеры, тест-раннеры).
