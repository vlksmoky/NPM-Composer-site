Глоссарий

Начните печатать, чтобы найти нужный термин.

Зависимость (dependency)

Внешняя библиотека или пакет, код которой ваш проект использует, но не пишет сам.

Манифест

Файл проекта, где перечислены все зависимости и их допустимые версии. У NPM это package.json, у Composer — composer.json.

Lock-файл

Файл, в котором зафиксированы точные версии всех зависимостей (включая вложенные), чтобы сборка была одинаковой у всех разработчиков.

Semver (семантическое версионирование)

Формат номера версии МАЖОР.МИНОР.ПАТЧ, например 2.14.3. Мажорная версия меняется при несовместимых изменениях, минорная — при новых возможностях без поломок, патч — при исправлении багов.

devDependency / require-dev

Зависимость, нужная только на этапе разработки (линтеры, тестовые библиотеки), а не в боевом окружении.

node_modules

Папка, куда NPM устанавливает скачанные пакеты вместе со всеми их собственными зависимостями.

vendor

Аналог node_modules в мире Composer — папка с установленными PHP-пакетами.

Автозагрузка (autoload)

Механизм, при котором классы из подключённых библиотек подгружаются автоматически, без ручного указания пути к каждому файлу.

Реестр пакетов

Публичный каталог, откуда менеджер скачивает пакеты: npmjs.com для NPM, packagist.org для Composer.

Дерево зависимостей

Структура, в которой у каждой зависимости могут быть свои собственные зависимости — менеджер пакетов разрешает такие цепочки автоматически.
